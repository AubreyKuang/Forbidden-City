# 同生手足：身份、对话与共同经历

双生、三胞同生的孩子有共同的生日，也各有性情、喜好和前程。此模块提供 10 组场景、20 个回应分支，与原有「宫中故事与后话」并行。

## 身份与入口

| 同胎组成 | 宫中贺称 |
| --- | --- |
| 两位皇子 | 双龙并耀 |
| 两位公主 | 双凤齐鸣 |
| 一位皇子、一位公主 | 龙凤呈祥 |
| 三位皇子 | 三龙同辉 |
| 三位公主 | 三凤同辉 |
| 两位皇子、一位公主 | 双龙伴凤 |
| 一位皇子、两位公主 | 双凤伴龙 |

标签出现在皇嗣列表、人物详情和家族名册。详情的「同生手足」列出可点击的兄弟姐妹，以及同生哥哥、姐姐、弟弟、妹妹的称呼。出生先后保留在诞生簿说明里，皇子、公主的宫中排行仍按原规则分别记载。

可从人物详情选话题；三至五岁的活动也出现在御花园，六岁起出现在上书房及宫城动向。国师贺生与成年家书从人物详情进入。自然生产概率仍为双胎 2%、三胎 0.1%。

## 已实现的场景

每题有两个回应，另外可免费暂缓。同一组手足完成互动后至少间隔六个月，每题只经历一次。每次回应消耗一点精力，国师题笺另花三万两、留灯另花两万两；其他题目不花国库。

| 话题 | 年龄与额外条件 | 可以怎样回应 |
| --- | --- | --- |
| 国师贺同生 | 0–2 岁，生母在宫且可探望全部孩子 | 各写瑞笺；听瑞梦、各留平安灯 |
| 我们各有名字 | 3–5 岁 | 逐个叫名字、问喜好；互相介绍小秘密 |
| 只早了一小会儿 | 6–10 岁，有完整出生先后记录 | 长幼照实记、日常轮流；谈谈怎样照应手足 |
| 龙凤也有各自的志向 | 6–15 岁，一男一女双生 | 各选试学课；互教一件拿手事 |
| 贺词之外的两个名字 | 6–15 岁，同为皇子或公主的双生 | 分别点评功课；互讲对方的用心 |
| 三枝都要有地方 | 6–15 岁，三胞同生 | 各选一枝、互留位置；合画一树、各自落款 |
| 别总拿我们相比 | 8–17 岁，至少一人好胜、自矜或内敛 | 各定目标；各按长处合作 |
| 替你说一句 | 9–17 岁，至少一人仁厚、爽直或好胜，彼此关系均不低于 15 | 查清误会、道歉；先收拾纸页，再让本人说明 |
| 同生未必要同行 | 12–17 岁 | 分别试学；保留每旬相聚 |
| 同日生辰，两地灯火 | 16 岁起，生辰月，至少一人已离宫 | 分别回信、转交问候；各写近况存入纪念匣 |

对话读取八种皇嗣性情；婴幼儿不说少年台词。国师按自身性情讲星影、云气或并蒂花的传说，生母也按性情回应。龙凤、双龙、双凤的贺称不会规定人物兴趣或储位。

三胞同生的故事由三人一起参与，全部两两关系都会受到回应影响。「三枝都要有地方」中，挪开绦带的人、扶枝的人、终于得到位置的人会分别记住自己的感受。人物成长记、主观记忆、共同经历和起居注保留结果；近期人物心声会提起实际选择过的事情。

## 出席、旧档与存读档

- 当面互动须全部同生手足在宫，已赐名、健在、体魄不低于 40，且无收押、寺居、移出宗籍等限制；丧期暂停。家书采用通信，不把离宫者拉回现场。
- 同组共用间隔，换一个兄弟姐妹打开也不能重复结算；暂缓、精力不足、出席条件变化不会扣费。
- 未完成的选择、已结算结果、关系变化与个人记忆随存档恢复，重开结果页不重复加成。
- 只使用明确记录的生产批次认定同生，不凭同月同日生日拼凑。旧三胞档若组成不足，只显示「三曜同辉」，不虚构性别。
- 手足离世后保留出生身份与旧事，但停止需要全员出席的互动。换婴查明后撤除抱来者误认的同生身份；寻回原孩子时承接其原出生批次。

## 阅读来源与改编边界

| 来源 | 使用方式 |
| --- | --- |
| [《西京杂记》卷三](https://zh.wikisource.org/wiki/西京雜記/卷三) | 霍妻双生与长幼之议，提及双男、双女及男女双生。属于古代笔记；不据此改写本游戏的出生先后或皇家制度。 |
| [《世说新语·德行》](https://zh.wikisource.org/wiki/世說新語/德行) | 元方、季方各有可称之处，借意写面对比较的感受；不称原人物为双胞胎。 |
| [《续齐谐记》](https://zh.wikisource.org/wiki/續齊諧記) | 田氏三兄弟与紫荆树的志怪传说，借同株写三人互留位置；不当作三胞胎史实。 |
| [《诗经·小雅·常棣》](https://zh.wikisource.org/wiki/詩經/常棣) | 借手足相念、相助之意写作证与生辰家书，保留亲人间的分歧。 |

祥瑞贺称、瑞梦、台词、人物和选择结果属于游戏创作。界面分别注明古代笔记、志怪传说、诗意改编与原创演绎。

## 实现与验证

`js/multiple-births.js` 处理身份、出席、地点入口、共同间隔、关系和记忆；`js/multiple-births-data.js` 保存全部题目、分支和来源。`tests/palace-multiples.test.cjs` 覆盖全部 20 条回应、七种标签、旧档、全员出席、换婴寻回、资金与精力、共同间隔和行动存档恢复。
