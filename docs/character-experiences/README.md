## 怎样遇见这些经历

- 共 **32 类连续经历**（10 类原有经历、1 条固定剧情妃经历、21 条三章人生长卷）与 **64 个可独立发生的短篇个人经历**。旧档已作出的选择保持原样；人物不需要走同一条强主线。
- 新经历按性情、兴趣、情分、位分、失宠处境和亲子状况筛选。每人每题只经历一次；同题全宫至少间隔四十八个月。全宫至多每三个月提出一件新事，同时至多三件未完；一人收尾后至少十二个月才有下一件。达到条件仍有随机性，不是每月必出。
- 在宫中动向看见她的消息，到人物详情「她自己的事」回应。陪她处理花一点精力，二至四个月后再听后话；也能让她自主处理或暂时搁置。它们不会每月强制弹窗。
- 才情、德行或心情影响后话更可能有所成还是有遗憾。回应留下属性变化、个人纪事与长期记忆；母子题目还会影响教养与母子信任。冷宫、离宫、死亡不允许日常面见，正在进行的经历会暂缓。
- 下列“有所成”“有遗憾”是游戏分支，不是史书结论，也不是原著人物的必然结局。所有新对白与情节均为原创改编。

## 人生长卷

21 条长线各有三章，每章两种回应，选择与前文一起进入下一章；两次续章至少相隔三个月。每人同时一条，收尾后至少一年才能再开新卷；自动邀约全宫至少隔半年、同时最多两条，同题隔三年。人物详情可主动选择全部符合条件的题目。原有专属经历与短篇经历仍可保留。

## 异乡与门第

微服逛集市有低概率救助成年异乡女子，每朝最多一次。救下后可护送离开、由官府安置，或经本人愿意暂住宫中客舍。客舍入口位于“出巡”；每两个月可陪她学写家书，至少相处六个月、信任达到五十才可自愿册为答应或开启寻亲。未入宫籍时也能寻亲，救命之恩不自动转成婚姻。

门第与异乡隔阂通过当面奚落、借宫规排挤、宫人怠慢份例表现。不同性格表现不同，孤高与持重者不自动变为欺凌者；纠正待遇、只作赏赐安抚、默认怠慢会留下不同关系与记忆。全宫至少隔一年，同一受影响人物至少隔两年。偏见属于人物行为，不是对出身或族群的事实判断。

## 省亲与家中病讯

重病母亲留家诊治，可派太医上门或准妃子回家探病。一般省亲可定一至三个月，位分和宫室保留；暂离时不可在宫中偶遇、召幸、探望或参加宴席，期满回宫，也可提前召回。体弱到不宜出行、孕程已满五个月、有家眷正在宫中探亲等情况下暂不安排。异乡失联亲人须走寻亲线索，不能凭空生成家中病讯。

## 婚前与婚后

选婿、选妃的名帖保存同一人的姓名、形象和性情。相看时可谈共同兴趣、独处与相伴的节奏、用度习惯。婚后不因一次决定便固定为幸福或不幸。

- 夫妻信任与家庭和睦持续保存；每四至七个月写一则日常纪事，避免连续同题。不同兴趣、用度、亲族、冷宫母亲与远嫁状态改变内容。
- 夫妻共同读书、安排空间、商量起居、向母亲请安或通信、与姻亲往来、抚养孩子和备孕照护，都可留下日常记录。
