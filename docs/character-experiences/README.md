## 怎样遇见这些经历

- 保留 **10 类原有连续经历**，新增 **64 个可独立发生的个人经历**。旧档已作出的选择保持原样；人物不需要走同一条强主线。
- 新经历按性情、兴趣、情分、位分、失宠处境和亲子状况筛选。每人每题只经历一次；同题全宫至少间隔四十八个月。全宫至多每三个月提出一件新事，同时至多三件未完；一人收尾后至少十二个月才有下一件。达到条件仍有随机性，不是每月必出。
- 在宫中动向看见她的消息，到人物详情「她自己的事」回应。陪她处理花一点精力，二至四个月后再听后话；也能让她自主处理或暂时搁置。它们不会每月强制弹窗。
- 才情、德行或心情影响后话更可能有所成还是有遗憾。回应留下属性变化、个人纪事与长期记忆；母子题目还会影响教养与母子信任。冷宫、离宫、死亡不允许日常面见，正在进行的经历会暂缓。
- 下列“有所成”“有遗憾”是游戏分支，不是史书结论，也不是原著人物的必然结局。所有新对白与情节均为原创改编。

## 稀有背景：异世来客

独立于原有性情的稀有背景，不计入上面的 64 个经历。人物自述来自二十一或二十二世纪；才情与处事心机影响是否急于自证，谨慎者相处满一年、情分达到 75 后才会袒露。被视作做梦或被讥讽后永久收起这一话题，存读档与提高情分不会消除此事。

同类先试探词语，再隔数月核对生活细节，才彼此相认；性格与原有交情继续起作用。可相信、倾听、拒绝、收押、送寺或请国师禳解。人工智能世界是人物猜想，属于原创架空情节。完整条件与分支见 [异世旧梦](time-travelers.md)。

## 原典与改编边界

- [《红楼梦》人物与日常意象](https://zh.wikisource.org/wiki/紅樓夢（程甲本）)：小说意象；各人的际遇由玩家选择重新演绎，不照搬原著结局。
- [李清照《金石录后序》](https://zh.wikisource.org/wiki/金石錄後序_(李清照))：收藏、校书与散佚的意象。
- [《后汉书·列女传》蔡琰记载](https://zh.wikisource.org/wiki/後漢書/卷84)：记书、流离与亲情的意象，不把虚构妃嫔当作历史人物。
- [《世说新语·言语》咏雪](https://zh.wikisource.org/wiki/世說新語/言語)：咏雪、才思与家庭讲学的意象。
- [陶渊明《归园田居》](https://zh.wikisource.org/wiki/歸園田居)：田园、守拙与自主生活的意象。
- [白居易《琵琶行》](https://zh.wikisource.org/wiki/琵琶行)：旧艺、倾听与身世的意象。
- [《怨歌行》团扇意象](https://zh.wikisource.org/wiki/怨詩_(班婕妤))：传统题为班婕妤，作者归属有争议；只取团扇与冷暖意象。
- 宫廷生活原创：原创生活情境，不冒充史实。

《红楼梦》的海棠社、香菱学诗、探春理事、黛玉惜花、湘云花下小憩、妙玉茶具、惜春作画、迎春退让、凤姐掌事、元春省亲、李纨教养、巧姐与旧恩、秦可卿的远虑，以及晴雯、平儿、鸳鸯等人物的处境，分别用于不同题目的意象。并不按某个标签把游戏人物写死，也不把原著的悲剧全套移植。相关篇章可从原典目录按回目核对。

```bash
node scripts/build-experience-catalog.cjs
```
