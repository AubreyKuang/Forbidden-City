# 异世旧梦：稀有来客背景

[返回游戏介绍](../../README.md#异世旧梦来自未来的她) · [返回人物经历索引](README.md#稀有背景异世来客)

这是原创架空支线。人物所说的未来、时空乱流与 AI 世界都属于她的自述和猜测；游戏没有因此接入大模型服务，也不要求 API 密钥。

## 来处与性格

妃嫔背景依人物种子一次确定，约 4% 的人物拥有。旧档可在月度推进或闲谈时补齐，反复打开详情不会抽取；亲姐妹不自动共享来处。原有性情、兴趣、家世和人生经历继续保留。

- 二十一世纪：末班地铁、雨夜屏幕、旧城书店。
- 二十二世纪：星港候船、人造春天、归途断讯。
- 才情与心机的均值低于 45，且不是聪慧、持重或城府性情时，更容易慌乱而急于自证；入宫至少一个月后可说起，后续至少相隔六个月。
- 其中才情不高于 40、心机低于 30 的冒失来客，会在选秀觐见时直接说出来自二十一或二十二世纪。实际看到她觐见才记为听过；只看名册不会凭空获得这段记忆。入宫后的自述承接选秀失言，慎重者继续隐藏。
- 其余人物谨慎藏言，入宫至少十二个月、情分至少 75 才肯坦白；后续至少间隔十二个月。低才情但善于处事的人不会一概写成张扬。

## 皇帝的回应

| 回应 | 留下的结果 |
|---|---|
| 相信来处、替她守密 | 情分 +8、心情 +10，继续讲述旧日生活 |
| 不急着定论、屏退宫人静听 | 情分 +4、心情 +6，保留以后倾诉的可能 |
| 当作一场梦、劝她不再说 | 情分 −6、心情 −6，此后不再向皇帝讲述来处 |
| 讥讽、斥为胡言 | 情分 −16、心情 −15，永久缄口，保留受伤记忆 |
| 命人拿下 | 再次复核后押入冷宫，停止宫内会面，永久收起倾诉；皇后另有废后代价 |
| 赴护国寺祈福 | 国库 −10，三个月后回宫；有孕不能安排，记忆保留 |
| 请国师禳解 | 国师先听来处，可花国库 10 行禳解祈安之仪，也可听其劝解、让她安居；没有附邪或失忆的自动判定 |

重新提高情分、读档或放出冷宫，都不会取消已经作出的缄口决定。普通生活、母子与喜好对白仍在，不会整个人只剩这一个背景。

## 同类相认

两人须在宫中、未病重，且同住一宫、兴趣相投或交情达到 15；交情低于 −20 时不安排私谈。有一人正在处理个人坦白选择时，也不同时安排双人事件。

1. **似曾听过的词**：偶然听见“手机”等词，先试探，不立即确认。允许继续谈话时，交情 +4。
2. 至少六个月后，**原来你也记得**：核对旧日纪年和具体生活细节。不同世纪的记忆不完全相同，仍能逐步认出彼此。交情 +14，双方心情 +7。
3. 相认后至少十二个月，**灯下说故乡**：可以谈家人、争论记得的年代和世界来处，继续留下个人纪事与对方视角的记忆。

皇帝可以不打扰、当面追问或让她们各自回宫。追问时，只要有一人已经缄口或情分不足，就不会轻易交出秘密；各自回宫会延后下一次机会，不删除已经发生的相认。

自动弹出同类事件与自述，全宫至少间隔六个月，并受原有事件调度与重复控制约束。见过的未决选择、人物背景、相认阶段和结局全部随存档保存；冷宫、寺居、离宫、死亡与病重人物不会出现在普通私谈中。
