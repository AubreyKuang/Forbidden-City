# 王府与就藩

## 在游戏里怎么玩

从「出巡 → 王府」可以找京中王府和外地藩邸，也可从皇嗣或先朝皇亲的档案进入同一座王府。府内可查看居处、王妃和孩子、人物纪事，并点生母姓名查看档案。太子居东宫。

| 处境 | 可做的事 |
| --- | --- |
| 在京开府 | 花一点精力到府探望，问近况或听家常。年满十六可商议就藩，选择西安、太原或开封。出京后朝臣支持下降 20 点，最低为零。 |
| 已在外地就藩 | 花一点精力寄家书，下月从王府读回信。寄出后先等回信，再议行止。两次迁居至少间隔六个月，可奉诏召回京中王府。 |
| 旧档标记已就藩，藩地未载 | 王府仍可访问。点「补录藩地」登记一处藩邸，补录不会再次扣除朝臣支持。 |

探望、家书及回信写入皇子纪事和起居注，记录每次就藩和回京，也会写入生母的纪事（若人物档案仍在）。书信和朝臣支持的数值用于游戏节奏。

## 长史按季呈报

转入正月、四月、七月和十月时，外地藩邸的长史递来奏报。多个王府在同一弹窗汇总，之后可从「出巡 → 王府 → 长史奏报」逐项批阅。旧存档中已就藩的王爷也适用，暂缓的事项留在王府待批。

| 事项 | 触发与批示 |
| --- | --- |
| 禄米 | 每季呈报。可照例支给（国库 −12 万两）或减半支给（−6 万两）。未批的禄米奏报延续至下一季，同类事项只保留一份。 |
| 王府修缮 | 首次呈报，此后距上次批示至少十二个月才会再报。可准修并拨款（−20 万两），也可准修、由王府自筹。 |
| 婚礼用度 | 礼部已登记近期婚事时呈报。同一场婚事只呈报一次。可赐婚仪银（−15 万两）或准照礼制办理、由王府自付。 |

每项批示及实际拨款写入王爷的纪事和起居注。国库不足时可暂缓，或在修缮和婚礼奏报中选由王府自付。

## 世子与袭爵

王府有在世的儿子时，长史会呈表，请从「王府 → 世子与袭爵」批阅。人选先列王妃所生的儿子，同一身份按年长顺序。皇帝可册封其中一人为世子，或留中待议。册封后可在王府阅读孩子及其母亲的纪事。

世子先亡时，长史报丧，世子位空出。有其他在世儿子，可从王府批阅另立；没有儿子时，可从兄弟家择一个尚未册为世子的儿子过继。在两府的「世子与袭爵」都可查到同一个孩子，生父母与承袭身份各有记载。孩子、仍在世的生父母与嗣府的人各有纪事。

王爷薨逝时，长史递讣报并请世子承袭。没有在世世子时，可从现有儿子另议；没有在世儿子时，也可批阅过继并承袭。准袭后，新王沿用原来的身份和府邸，地方藩邸仍在原地，待批的长史奏报也会交接。幼王的府务暂由长史料理。府主的寿终时点按人物固定，达到高龄后在转月时判定。请封、报丧、过继和袭爵分别进入相关人的记事和起居注。

## 明清史料如何用进游戏

- **明式就藩与府官。** 《明史》卷一百一十六记载皇子封亲王后受册宝、给岁禄、置官属。卷七十五列有王府长史司，长史负责总理府务、规谏藩王，并代呈册封、婚姻等章疏。故宫博物院的研究列出秦王就藩西安、晋王就藩太原等例，周王一系的藩地为开封。游戏将这三个地方作为可选地点，保留原有封号。 [《明史》卷一百一十六](https://zh.wikisource.org/wiki/明史/卷116) · [《明史》卷七十五](https://zh.wikisource.org/wiki/明史/卷75) · [故宫博物院所载西安与太原藩封](https://www.dpm.org.cn/Uploads/pdf/2211/T00014_00.pdf) · [《故宫学刊》所引周王封开封记载](https://www.dpm.org.cn/Uploads/File/2020/03/31/u5e82be12b6fe2.pdf)
- **府务与地方政务。** 《明史》卷一百二十称诸藩「列爵而不临民」，同时记下明初宗藩备边和后来藩禁趋严的变化。游戏里的长史照料王府并呈报禄米、修缮和婚礼，州县事务继续由现有官员处理。 [《明史》卷一百二十](https://zh.wikisource.org/wiki/明史/卷120)
- **清式留京赐府。** 恭王府博物馆展览介绍了清代宗室按爵赐京城府邸，以及内务府监修、按爵位规定建筑的制度。部分王公奉命议政或领兵。游戏的京中王府适合延展为探望、赐府修缮及受命办差，差事仍由皇帝授予。架空朝代允许这条路线与明式就藩并存。 [恭王府博物馆「清代王府文化展」](https://www.pgm.org.cn/pgm/qdwfwhz/zl_bf.shtml)
