# 锦衣卫稀有事件速报

锦衣卫成立且指挥使在任后，关键事件会先弹出急报。点「阅毕，查看原事」继续原剧情和原有处置选项。来访、传闻与私笺等见闻只在原剧情附报。只有实际呈到玩家面前的事件才会入档，可在锦衣卫的「稀有事件速报与新怨密报」和起居注重阅。

| 方式 | 已接入事件 | 缇骑可知的线索 |
| --- | --- | --- |
| 急报 | 香囊疑案、石阶惊变、巫蛊之祸、东宫惊魂、狸猫 | 查现场、物证、值宿簿和宫门出入 |
| 急报 | 襁褓上的旧结、迟来的脉案、宫外家书 · 身世起疑 | 核对太医脉案、婚籍、接生簿和经手人口供 |
| 急报 | 皇子结党、兄弟阋墙、储位之争、逼宫、遇刺 | 核府门来客、朝班、禁门急报与随驾见闻 |
| 附报 | 起居簿外的疑问、夹在书中的笺子、回廊相依 | 核对簿册、经手人和当值侍从，分开记录亲见和转述 |
| 附报 | 宗人府 · 宗亲遗孤 | 核对讣文、府册和孩子目前的照料人 |
| 附报 | 出生时地动、出生逢旱、钩弋之遇、仙师来访、江湖闻名 | 核地方快报、随驾名册、来客名帖和驿传信牒，传说照原话存疑 |

同一人的兄弟阋墙或储位之争，首次报过以后，六个月内再有同类消息只入档。宫中妃嫔正式结怨，或她们与同辈之间、年满十五岁的皇嗣与同辈之间关系降至 −40 时，会有新怨密报。同月最多弹一次，同一对人物六个月内只报一次。密报写明两边是谁、有什么可查，并保留原有查证和处置入口。

版本 64 及以前的未完事件按原样重放。原事件完成后，下一次新事件使用急报规则。

在同一标签页点过急报或新怨密报后，即使立刻刷新、自动存档还在写入，读取自动存档也会接着往下走。急报接回原事，新怨密报直接收起。未阅的密报仍可照常读档续接。
