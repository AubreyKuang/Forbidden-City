# 锦衣卫稀有事件速报

锦衣卫已设立且指挥使在任时，下列事件实际打开便会收到一段附报。弹窗会保留原有选项，提示可在锦衣卫的「稀有事件速报」和起居注重阅。同一人的同一线索重复打开只入档一次；再次发生的独立宫闱案、遇刺或储位冲突可另行入档。

| 场景 | 已接入事件 | 缇骑可知的线索 |
| --- | --- | --- |
| 宫禁疑案 | 香囊疑案、石阶惊变、巫蛊之祸、东宫惊魂、狸猫 | 查现场、物证、值宿簿和宫门出入 |
| 亲缘与医案 | 起居簿外的疑问、襁褓上的旧结、迟来的脉案、宫外家书 · 身世起疑 | 核对太医脉案、婚籍、接生簿和经手人口供 |
| 私笺与见闻 | 夹在书中的笺子、回廊相依 | 复核经手人或当值侍从，只记亲见和转述 |
| 储位与扈从 | 皇子结党、兄弟阋墙、储位之争、逼宫、遇刺 | 核府门来客、朝班、禁门急报与随驾见闻 |
| 祥异与来访 | 出生时地动、出生逢旱、钩弋之遇、仙师来访、江湖闻名 | 核地方快报、随驾名册、来客名帖和驿传信牒；传说依原样存疑 |

附报提供核对方向。需要查证时，继续使用事件中的调查选项或锦衣卫已有的立案功能。款项、处罚与身世认定由原来的玩法处理。
