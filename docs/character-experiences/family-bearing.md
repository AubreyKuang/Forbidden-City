# 家世、用度与宫中立足

家世影响一个人熟悉什么、在意什么，也影响她初入陌生环境的底气。它与性格、当前位分和入宫年限一起起作用。

| 来处与境遇 | 初入宫时 | 住久以后 |
| --- | --- | --- |
| 高门、世家 | 熟悉精致器物与待客礼数，通常不为添衣发愁；仍需另学宫规 | 更在意如何表达自己的主意，不只依靠家门 |
| 皇商、富商 | 辨得出料子、价钱，用度宽裕；不会因此自动熟悉宫中礼序 | 会分清物件的价值与人情的分寸 |
| 清贫书香 | 书中道理熟悉，实际席间进退未必熟悉；会打算零用 | 学会礼数后，更敢说出自己的理解 |
| 寒门、农家 | 可能观察旁人的落杯、起身与让座，回屋再练；留心添置与随礼的开支 | 礼数熟练后不再处处模仿，即使零用仍紧，也可以有自己的底气 |
| 普通官宦、医家等 | 有原本的生活经验，不默认贫困，也不默认什么都懂 | 将家中习惯与宫中生活慢慢磨合 |
| 异乡女子 | 外邦贵女有自己的礼仪；获救的流寓女子更关心能否自己安排用度 | 适应本朝礼数时仍保留来处与自主选择 |

同为寒门，温婉者可能先看后学，骄矜者会把袖口抚平、撑住体面；活泼者会问错再笑着记住，城府或持重者先记次序、安排花用；才女与好学者想弄明白规矩的缘由。孤高者独自习礼，受了照应也不会自动变得好交游。体弱者会停下来休息。

## 从哪里看到

- **选秀觐见**：登场动作和开口的话体现家世；才艺、穿越者自曝等原有内容保留。
- **本批选秀结束**：新妃安顿页展示她的反应，并写入人物纪事。
- **入宫六个月内问候**：可以安慰、安排姑姑讲礼数；手头紧的低位妃嫔多一个“另赐安置银”选择。
- **宫殿迎驾、人物页**：举止有家世与熟悉程度的差异。
- **闲话家常**：初来的平和心境、后续家世话题与真实生活纪事互相呼应；一次只谈一个话题，病痛、丧子与紧急家事优先。
- **人物纪事**：新增席间分寸、用度与心意、学来的礼与自己的心、旧日习惯四类小事，妃嫔与成年姐妹分别使用宫中、家中语境。

安置银仅能在这次安顿时选择一次，花费 1 点抽象国库预算，缓解六个月的零用顾虑，并记录她怎样领受这份照应。它不是历史银两定额。之后晋至嫔位或获较多恩宠时，她也不再一味说自己用度窘迫；入宫前的习惯与家世不会被升官、晋位改写。

这些差异没有把寒门女子设成吃不饱饭：宫中基础衣食有份例，她们更多顾虑的是额外添置、个人喜好和人情往来的余地。已有旧档只依据现存的家世资料判断，不虚构已丢失的入宫前家境。

纪事沿用低频规则：全宫至少隔三个月才尝试一回，尝试概率为 35%，每次至多一人；同一人至少隔十二个月，同一条至少隔三十六个月。不会每个月给所有妃嫔刷同样的记事。

## 文学与历史参考

- [《红楼梦》第三回](https://www.shidianguji.com/book/SWX0005/chapter/1kzxy54u6fgov)：借鉴黛玉入贾府时观察座次、礼数与他人举止的写法。黛玉并非寒门女子，这里借的是陌生环境中的谨慎。
- [《国朝宫史》卷十七](https://zh.wikisource.org/zh-hant/國朝宮史_(四庫全書本)/卷17)：宫中铺宫、年例与日用按身份定例，不能简单将家世清贫写成没有基本衣食。
- [故宫博物院：宫分与削减肉额相关研究](https://www.dpm.org.cn/Uploads/File/pdf/1b/46/b1/1b46b14ca36f92972db7de1595295f2b.pdf)：宫分既有制度规定，也有实际执行和调整。游戏据此区分基本份例与可自行支配的零用，不照搬具体数量。

人物对白与生活小事均为原创化用，不作为史载人物事迹。
