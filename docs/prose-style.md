# 宸宫纪文风准则（内容版本 172 起）

2026-11-28 对照易次元两部作品的文字做法后定下。代码在 `js/prose.js`，测试在 `tests/palace-prose.test.cjs`。

## 参考作品是怎么写的

| 作品 | 值得学的做法 | 例子 |
| --- | --- | --- |
| [《帝梦之后宫天下》](https://avg.163.com/game/detail/25495) | 命格、特质用四字名加一句判词；受宠与失宠各有一句评语；风闻用章回体标题；开场注明“部分事件、文本改编化用自历史、文学典故” | 【镜花水月】后面跟的是“拂墙花影动，疑是玉人来”；风闻标题“傅母巧施连环计，驸马误上断头台” |
| [《江山千秋万代》](https://avg.163.com/game/detail/368816) | 简介以一联宫词开篇，再转入第二人称的白话；人物心情用一句短语点出 | “日暮迎祥对御回，宫花载路锦成堆。”；心情提示“做了坏事的不安” |

两部作品的共同点是：记事保持编年体的简短，文采放在标题、判词、题记和开篇这些固定位置上。宸宫纪照这个分工来做。

## 宸宫纪的写法

1. **记事用史笔，场面用白描。** 起居注、人物纪事保持一句话的编年体。事件正文写看得见的东西：器物、动作、天气。
2. **典故放在固定位置，正文里只化用。** 直接引用的诗文放题记，并标出处。正文里化用一句即可，不整联照搬，也不解释典故。
3. **哲思落在具体的物上。** 一段最多一句，接在实物后面。例如“冰窖的冰一车一车往各宫送，送到最远的那一处，只剩半盆水。恩泽大抵也是这样走的。”
4. **引文必须查得到。** 只用能确认原文和出处的句子；拿不准的不用。出处写作者加篇名，或书名加篇名。
5. **不用现代词和网络语。** 称谓、器物、官制沿用游戏里已有的写法。
6. **一处只添一层。** 一个事件有了题记，正文就不再重复同一句诗。

## 改写已有文字时的规矩

事件标题、选项文字、结果文字、纪事和起居注都会写进存档，回放未完事件时要逐字一致（见 `js/action-journal.js` 的 `restore`）。因此：

- 改写这些文字时写成 `pz('旧文','新文')`，旧版本留下的未完事件仍按旧文重放。
- 事件标题不改。题记按标题查表，改了标题也会让旧存档对不上。
- 新增的挑选逻辑不调用 `R()`、`pick()`、`chance()`，只按回合数和标题取（`prosePick`）。多取一次随机数会让之后的回放全部错位。
- 只作显示的文字（月令、题记、判词、场景）不需要 `pz()`，但要在 `proseActive()` 为假时不显示。
