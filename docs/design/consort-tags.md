# 妃嫔黄色特质标签候选

2026-11-16。以下为供选方案，尚未加入游戏。已上线的心境显示使用粉色；太后族亲使用灰色。

## 代码与分布依据

`makeGirl()` 的数值由基础整数随机值叠加性格修正，再限制在 0–100。不是所有属性都随机到 100。

| 属性 | 基础范围 | 主要修正 | 18,000 名样本的中位数 / 95 分位 / 最高值 |
| --- | --- | --- | --- |
| 容貌 | 40–88 | 骄纵 +5、骄矜 +6、体弱 +8 | 65 / 87 / 96 |
| 才情 | 30–85 | 聪慧 +12、才女 +20、巧手 +10、好学 +8 | 60 / 85 / 100 |
| 德行 | 30–85 | 温婉 +12、淡泊 +6、持重 +9 | 59 / 84 / 97 |
| 心机 | 15–75 | 善妒 +14、城府 +24、淡泊 −15、沉静 −5、爽直 −8 | 46 / 74 / 99 |

样本由 30 个固定种子的新局，各连续生成 100 批、每批 6 名秀女。调用真实 `genCands()`，包含候选性情平衡与亲族替换；各局保留两位开局妃嫔，不录取后续候选、不推进月份。特殊剧情妃、玩家挑选偏好、长期培养和剧情属性增长未包含在这份分布中。统计是符合属性条件的比例，不是额外随机触发率。

可运行 `node scripts/analyze-consort-tags.cjs` 复现，原始结果见 [consort-tag-distribution.json](consort-tag-distribution.json)。

## 健康系列的前置缺口

普通妃嫔的 `makeGirl()` 与 `deepen()` 目前没有统一初始化 `hp`；18,000 名普通候选的健康值全部缺失。少数特殊人物另有指定值，例如钩弋夫人 82、异乡获救女子 65、鸿渐 85。部分判定用 `hp ?? 85` 或 `hp ?? 100` 作后备，这并不等于已经有一套会持续变化的妃嫔健康系统。

**「弱柳扶风」** 可按用户建议，以真实健康 <50 判定，但需要先完整定义普通妃嫔健康的初始化、疾病损耗、产后恢复和旧档补值。不能把缺失值当作 0，也不能假装已经测出其出现概率。

体弱性格在本次样本占 5.31%。若以后设计健康，可让体弱者更容易低于 50，普通人通常高于 50；确切范围与比例须连同月度疾病、治疗和产后过程一起验证。健康恢复后应撤下身体状态标签，不永久保留病弱称号，也不应仅为装饰随机扣减健康。

## 避免标签普遍化与信息泄露

- 黄色标签以事实和较高门槛为依据，不另外对每个人逐月抽签，避免多年后人人中签；默认不额外累加属性。
- 容貌、才情达到条件即可解释对应特点；才艺类后天名望还可要求实际献艺、作品或剧情记录。不能把一次普通听讲、送礼或闲谈直接当作终身特质。
- 德行、心机和未了解的喜好仍遵守现有暗访与相知规则。选秀尚未暗访时，不提前展示「深藏不露」「赤子之心」等会泄露隐藏属性的标签。上表计算潜在符合率，实际可见率会更低。
- 同系列只显示最有区分度的一项，优先复合条件；例如有「才貌双绝」时不再用三枚标签重复说容貌与才情。跨系列在名册最多展示两枚。
- 初始符合率不代表多年后比例。才情、德行、心机会随事件增长，后续上线应另跑多年模拟；后天标签宜结合真实成果授予。不要为维持全宫硬比例而剥夺真实符合条件人物的特质。
- 后宫人数较少时，可以一个黄色特质也没有；不强制每局补足，更不强制每人发一枚。
