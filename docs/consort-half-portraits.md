# 妃子大头照补齐半身图

本次覆盖正式妃子图库中 88 张只有头肩或胸像构图的立绘：82 张根据原画补绘至腰部附近，6 张复用此前已确认的对应半身画。其余原本已有半身构图的妃子立绘沿用原图。

美术稿已由用户确认全部采用，并要求校准首饰位置。

## 游戏中的显示

- 头像宽度不超过 84 时，继续使用原图和原来的近景裁切。
- 更大的详情立绘使用同一编号对应的半身图；已有半身图的编号继续使用原素材。
- `artPortrait`、`portraitOverride`、随机抽取池及存档中的编号均不变。钩弋夫人仍固定为 422；锦衣卫及官员不受影响。
- 首饰叠加按半身画的头部位置与比例放置。82 张补画逐张记录定位；白色、紫藤和牡丹的现有半身坐标也经过校准。半身图的侧簪向发髻内侧收拢，避免悬在头发外面；原大头图继续使用近景尺寸的首饰定位。
- 开发工具中的原始图集预览继续显示原图，便于核对编号。

## 可追溯素材与验证

`consort-half-portrait-plan.json` 记录每位人物的原画来源，以及 14 张扩图纸的顺序。
`consort-half-portrait-sources.json` 记录裁切、缩放、图集格位及首饰定位。
`scripts/build-consort-half-portraits.py` 只负责裁切、等比缩放和透明图集打包，不修改原图集。
`js/consort-portrait-details.js` 由该脚本生成。调整首饰定位时使用 `--metadata-only`，保留图集像素。

测试覆盖 88 组头像/半身对应、82 个唯一格位、真实素材存在、全部首饰、晋封、保存读取以及其他角色的素材不变。
