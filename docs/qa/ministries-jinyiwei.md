# 六部、科举与锦衣卫

## 六部（理政 →「六部」）
- 吏、户、礼、兵、刑、工各设尚书。人选须在任、才干 55 以上，一人不兼两部；兵部只用武职世家，新科进士须在翰林院历练满两年才可出掌文职各部。家世本就官居某部尚书的父亲，未另行任命前即为现任；改任他人时原尚书转任内阁学士。尚书去世、致仕或调任他职即视为卸任。
- 各部每年可办一件大事（精力 1），成功率 = 0.4 + 尚书才干/200：
  - 吏部 · 京察考课：全体在任官员评卓异 / 称职 / 不称职，信任随之增减并写入履历（有记载在案的疏失会拉低评等）。
  - 户部 · 清查亏空：入库 40 + 才干/2 万两；失败只追回 15 万两、民心 −2。
  - 礼部 · 开设恩科：下月加开殿试；两科至少相隔两年。
  - 兵部 · 整饬边备：武略 +3（失败 +1）。
  - 刑部 · 秋审复核：若有妃嫔因巫蛊被诬入冷宫（游戏已记下真正主使），可借此平反并传主使问话；否则开释错押者、民心 +3。
  - 工部 · 督修河工：修成即可抵一次黄河决口的修复开支。

## 科举
- 正科每三年三月（第 4、7、10…年）殿试；礼部可奏开恩科。三名贡士各有出身与策论，可钦点状元或交礼部按卷定次；三甲授翰林院修撰 / 编修，成为外戚之外有名有姓的朝臣，列入官员表并有个人详情页（可召见）。
- 外家子弟中已有举人功名者同场会试，能否中进士只看学业；中进士者可按既有流程核验科名授官。

## 锦衣卫（理政 →「锦衣卫」）
- 设立需精力 1、国库 50，生成一名指挥使；文官对“厂卫”心存顾忌（文官派影响力下降）。
- 案卷：香囊疑案、石阶惊变、巫蛊之祸、东宫惊魂未能当场查明时自动立案，立案时即记下真正的主使与受害者；锦衣卫只决定“能否查到”，不改写真相。设立后，这些事件里多出「交锦衣卫密查」。
- 密查：国库 15，下月回报；成功率看指挥使才干、已查次数与案龄；失败后半年可再查。查明后可传主使问话（进入原有「真相大白」处置）或暂不声张；巫蛊被诬者可同时平反出冷宫；主使已故或出宫则只记入案卷。
- 搜宫：只有确有案底的人才可能被搜出物证；搜不出东西，被搜者情分 −10、心情 −15、心生委屈，六宫人人不安，搜中宫威望损失更大。同一人一年内只搜一次。
- 同朝参本中的“风闻奏事”可改交锦衣卫核实，真伪在交办时即已定下。
