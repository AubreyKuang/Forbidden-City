# 岁时、迁宫与慈宁宫验收

适用内容版本：30。旧版未完事件按原规则续接，结束后再采用新规则。

## 规则与覆盖

- 皇嗣出生气象标签的数值效果在周岁及以后每次生日结算一次；上限为100、下限为0。旧档已得数值保留，不补发往年收益。
- 迁宫请求共用全宫及个人24个月间隔；主动谈居处和随机请求均遵守。请求提出即记录，答应、拒绝、暂缓都不绕过冷却；皇帝手动安排不受影响。
- 慈宁宫请安按钮位于标题右侧，在390像素手机视口内无需滑到底部。
- 同月反复请安有不同话题，第三、第四次可谈皇帝近况与童年。已有家庭新闻、丧亲悲伤及关系亲疏仍优先，悲恸期间不插入欢笑打趣。

## 验证

整合回归：1930项通过；六十个月流程脚本通过。
