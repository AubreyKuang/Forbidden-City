# 前尘梦回验收

验证日期：2026-11-14。功能发布：[PR #6](https://github.com/AubreyKuang/Forbidden-City/pull/6)，代码提交 `4ea2f763729aca138802fd29d3ffea05b2241442`。

## 规则与存档

- 已故、成年、非宫女、非离宫者且情分至少 50，才进入来源档案；首次观察到死亡后至少隔一个月再供选秀使用。旧档不伪造死亡年月。
- 每次有合适来源及成年候选的选秀有 12% 机会产生一位梦回者；不与亲族入选、异世穿越背景重叠。今生姓名、年龄、立绘、性情、家族保持独立。
- 每朝最多留选一位，每个前身只承接一次；未选中不占用。留选后即保存来源快照，后续去世不会再次复制同一前身。
- 同朝与跨代分开称谓。继位时排除生母与嫡母；旧传代存档同时根据已有太后身份和先朝皇后记录补齐排除。来源档案独立于最多五朝的旧宫廷缓存。
- 入宫满三个月、情分达到 35 / 50 / 65，依次开启三段对话，每段至少相隔六个月。病中、悲恸、怨恨、惶恐或无法在宫中出席时暂停。
- 每次回应扣一点精力，仅结算一次；暂缓不扣。月度主动邀请至少隔一年，只有进入队列才记录间隔。
- 国师问缘每人一次；孕晚期、体弱或病中改为本宫读笺。前尘作为原创志怪的魂梦自述，不修改出生时间，也不把梦札写成新帝亲历的记忆。

## 自动验证

`node --test tests/*.test.cjs`：20 个文件、488 项用例通过。`tests/palace-past-lives.test.cjs` 的 13 项覆盖资格、稀有度、候选退出、重复来源、今生身份、跨代称谓、旧档长辈排除、三段倾诉、两种结局与封缄、出席和冷却、未完事件恢复、国师问缘及扣费防重复。

`node tests/palace-flow.cjs`：连续 60 个月流程通过，含宴会、家族记忆、历史场景、存档、地图动向与自主后续。`git diff --check` 与脚本语法检查通过。
