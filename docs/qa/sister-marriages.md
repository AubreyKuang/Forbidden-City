# 娘家姐妹的议亲与婚嫁

## 规则
- **年龄**：二十岁以下不议亲；二十至二十九岁的姐妹或已出嫁、或正在议亲、或仍按自己的打算留在家中；三十岁以上一律已出嫁。第一次清点时按每人固定的记录补记（不靠抽签），已出嫁的只写进她本人的纪事，不在宫里刷屏。
- **议亲 → 成婚**：议亲 6–18 个月后成婚，消息写进她本人和宫中姐妹的纪事。未议亲的姐妹每年开春有一定机会开始议亲。已婚者不会再被安排婚事；原有「自己相识成婚」的家事在议亲期间暂停，避免一人两门亲事。
- **世家**（内阁首辅、镇国大将军、吏部尚书、两江总督、户部侍郎、翰林学士、知府、皇商）：优先与**交好**的世家议亲（对方须有未婚的成年兄弟），交恶之家不议亲、本家不议亲；找不到合适人家时嫁入其他官宦人家。两家结亲后，两位妃嫔关系 +6，双方纪事记「两家姻亲」。
- **小门小户**（县令、书香门第、太医院院判、寒门、农家等）：嫁与对应的普通人家——太医之家配坐堂郎中、药铺掌柜；书香门第配乡塾先生、书坊掌柜；农家配务农人家、木匠、货郎等。
- **议亲 / 相看事件**：或由妃嫔提起家书，或由宫人回报两家在护国寺、花朝会等处相看。世家可「赐婚成全」「由两家自行商议」「以防结党不准」（结亲双方关系相应升降）；小门小户可「赏一份嫁妆」或「由她家里做主」。每个回答都写入妃嫔本人纪事；同一门亲事只呈上一次。
- **平民父兄（新开局起）**：小门小户的兄弟是平民营生（务农、货郎、坐堂郎中、乡塾先生……）；寒门、农家、书香门第等的父亲也是平民，县令、太医院院判仍是在任官员。平民不上朝、不领差、不被举荐或参劾，也不会被御史以「截留赈银」弹劾，不列入官员表；详情页只保留「召见问候」。旧存档的家族保持原样。
