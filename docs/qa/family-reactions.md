# 家庭变故、姻亲与宫女留侍验收

适用内容版本：30。

## 行为

- 母亲死亡、离宫、降位、禁足罚俸和入冷宫的实际操作结算后，主动生成孩子反应、个人纪事及记忆。同母孩子、养子女和明确有交情的孩子分别使用真实关系称呼。
- 求情是有条件的概率事件。满四岁且亲近的孩子可发起，多名子女及真实好友可同行；远处孩子使用书信，婴幼儿只写起居和随侍代记，去世不生成求放出冷宫的选项。
- 同一事件处理后不再重复求情；后续探望每次只讲一小段近况，按年龄、性格、事件、次数与时间变化。长期冷宫的孩子逐渐恢复日常，仍可关心母亲；离宫子女不会在家书里突然出现在皇帝身旁。旧档现有冷宫母亲也可直接使用多轮探望，不补播历史处分。
- 正式赐婚连起两位妃嫔的家族后，立即排入姻亲对话；同种性格也有不同的应答，旧怨保留。不能当面相聚时分别传报心意，未成婚与修复旧婚书不会当作新婚喜讯。
- 得宠的低位妃嫔可以凭真实盟友组织派系；先保留有支持者的独立领袖，再按交情分配成员，皇后位分不覆盖其他人的交往。孤高、敌对、离宫等限制保留。
- 翻牌子下方有宫女留侍入口。旧识可主动再见，同月新当值人选固定；新宫女成年，召见不扣精力，确认留侍扣一次精力，衔接次日安置。有孕、恢复期和撤牌限制保留。册封当时初始化家族，刷新不再补出不同的资料。
- 随机月度宫女事件基础概率25%，御花园随机值区间`[0.5,0.75)`对应25%，实际遇见后共用6个月冷却。内廷人数和暂缓荐选仍可阻止新人物的自然荐入；主动召见不走随机筛选。
