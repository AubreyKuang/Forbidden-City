# 宫中亲情、地方实绩与钩弋：验收记录

## 验收方法

自动测试、60 个月连续游玩脚本，以及 Chromium 真实界面操作。浏览器使用隔离上下文，先从「存档」导入演示进度，再点击实际入口和选项；通过刷新、读取自动存档比较人物、纪事、关系、钱粮、精力及未完对话。页面内脚本只读取状态，不修改游戏世界。

场景存档用于覆盖分支，不代表这些事件会在一局里连续触发。桌面为 1440×1000，手机为 390×844。每个场景记录截图、脚本异常及页面横向溢出。

## 自动验证要点

- 十二类地方任务均覆盖普通成功、殊绩、疏漏；一千次模拟检查正面事件比例和题材轮换。优秀官员成功更多，仍保留合理的失败与善后。
- 入京任用检查才干 75、功绩 65、半年调任间隔、实际在任状态；离任、已故、未成年、被罢免及出差中不能借旧折再升官。重复点击不重复升职、赏银或增加功绩。
- 地方殊绩调入中央沿用品级选择岗位，不挤掉在任尚书；普通地方升迁沿地方官序。功绩、原奏、御批、前后官职均保留。
- 钩弋诞生祥瑞为 60%，普通妃嫔仍为 3%；男女婴各一千组概率输入均不产生地动／旱灾。体弱照护独立保留。
- 家族年龄对已故孩子保留可核实的享年；旧档缺少年龄依据时显示未详。
- 读档不得推进月度祈愿或出游；这些抽签仅在实际过月时执行。无法恢复的旧事务不再被新系统写入额外状态。
- 皇嗣玩伴按年龄差、性情、既有交情和共同兴趣加权；实际敌对者不自动成为玩伴。
