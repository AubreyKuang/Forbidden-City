# 朝政、宫中反应与自动转月验证

验证日期：2026-11-15。桌面与 390 × 844 手机宽度；浏览器场景使用隔离的本地测试存档，不改线上玩家进度。

全量回归 **800 / 800 通过**；另完成 60 个月流程检查和下列三种玩法各 60 个月的自然游玩。此处统计不把自然游玩的选择次数算作独立单元测试。

node --test tests/*.test.cjs

node tests/governance-browser-fixture.cjs
python3 -m http.server 8416 --bind 127.0.0.1

生成的 `qa-*.html` 仅用于本地实机验证，不发布。新的定向用例在 `tests/palace-governance-life.test.cjs`。原有 `palace-court` 金额用例隔离自动转月，以继续逐笔检查当月赈务交易；完整的自动结算、读档和后续事件由未隔离的集成用例覆盖。

## 检查范围

- 凤冠保持原大小，只在 112 × 140 的基准画布上向上移 6 单位；Canvas 与 file 页面共用位置。对照近景和半身立绘，包含侧脸。未更换人物面孔。
- 黄河督办与御史弹劾显示实际官员，身份索引与显示头像分开；数字人物 ID 先解析为人物对象，不再被画像函数当作无姓名对象处理。妃嫔仍保留家属案情纪事。
- 秋税每年十月入库；正月固定岁贡银和珍饰。覆盖按期结算、减税、重复打开、读档、次年再次收入，账簿与实际国库相符。
- 敬事房在六个月未往后宫相处时捧牌，暂缓后四个月再来。验证孕中、撤牌、离宫和国丧限制；捧牌选择可冷启动读档续接。
- 太后先说明母族表亲来处，按年龄称表姐或表妹；生母与嫡母母家的血缘、礼法关系分开记录。
- 温婉、持重、善妒、骄矜、淡泊、痴情皇后的选秀反应按性格与德行区分。善妒即使德行高，也不会突然毫无芥蒂；一人都未留下时不会凭空说“又添新人”。安顿仅在名单确定后商议，照料写入皇后与具体新人纪事。
- 五类调任岗位与六项扩充差务，核对资格、职位占用、退休、在差、待回奏与调任间隔。赴任半年考课，差事成败进入官员和家眷纪事，妃嫔心声提及实际姓名、官职与差事。
- 八种微服民情均覆盖拨款、交办、不能重复立案、到期复验、未妥补救与最终归档。具名承办官不能同时领其他差事；承办人身故或去职后由部院接手，不让故人继续办差。
- 最后一点精力在结果、取名及其他后续处理完后才自动转月。核对有弹窗、无弹窗、读档、存档写入失败回滚与只转一次。
- 以升级前提交 `95e71af8afba6bbc0e7a4d75acd9632420aec617` 的实际脚本生成八份未完事件存档，保留在 `tests/fixtures/court-life-legacy-v2.json`。覆盖闲谈、温泉、出城、选秀、十月结算、官员领差、太后荐人和端午分工：旧事件可续接、再次保存并冷启动恢复；结束后新行动启用自动转月。另核对旧委派页面的“暂不委派”索引不会错指新差事。
- 自然游玩发现端午“已分派、尚未验收”的中间阶段缺少纪事；补记两位主事的姓名、分工、拨款与验收约定，尚未最终选人时不虚记领差。
