## 游戏概述

玩家以皇帝身份在朝政、后宫和皇嗣之间分配每月精力。奏折、人物邀约和月末结算让决定影响国势与家族。皇帝驾崩或被迫禅位后，合适的继承人可开启下一朝；民变会终结王朝。

- 宫廷经营与家族叙事 · 网页 · 键鼠与触屏 · JavaScript / DOM / Canvas
- [ASSUMPTION] 目标玩家为喜欢长线人物关系与资源权衡的模拟玩家。

## 设计支柱

- 每月留一个清楚的取舍，玩家知道精力花在哪里。
- 朝政会牵动具体的人和家族。
- 人物的经历能从当月回响到下一代。

## 核心循环

看国势、奏折和邀约 → 分配精力与国库 → 批复或走访 → 月末结算与人物后续 → 推进下一月或传承。

## 首轮试玩

新档登基后可直接进入宫城，也可先选秀。首月奏折是黄河决堤。批复后从宫城走访具名人物，换月后在起居注查看收支、批复结果和人物记录。试玩观察玩家能否说清亲办和委办的代价，并找到上月与谁见面。
