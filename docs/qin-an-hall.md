# 钦安殿 · 问道与游历

[返回游戏介绍](../README.md#钦安殿国师与东海之约)

钦安殿在游戏地图右侧、文渊阁下方独立呈现，便于识别和点选，也能从御花园前往。这里的国师与人物对话为游戏原创，不是对某一朝代宗教制度的完整复原。男女国师各两种立绘，一个存档中固定一位；来访文士、女史与女客另用独立图集。

## 人物怎样来到这里

性情淡泊、沉静、好学，或暂时失意的妃嫔，以及满十二岁、住在宫中或京中府邸、野心较低或才学较好的皇子公主，可能主动来访。已有问道经历的人更常来，每月最多展示四位在场者。信佛、偏好佛经的人不会因此自动转为向道；冷宫、寺居、圈禁、就藩或远嫁、病重及孕期需要休养者不参加常规听讲；孕中祈愿另按孕期与身体情况安排。

来访记录随月份累计，每月同一人只记一次。反复打开页面不抽取新的来访者、不增加次数；去过三次后可在日常闲谈中说起问道，六次后显示「潜心问道」。这些是额外经历，不覆盖原有性格。

| 鲲鹏之问 | 《庄子·逍遥游》 | 宫墙之外的天地、远行所凭借的条件 |
| 濠上观鱼 | 《庄子·秋水》 | 自己眼里的自在，是否就是旁人的快乐 |
| 梦蝶 | 《庄子·齐物论》 | 暂忘称谓与处境，梦中片刻的自由 |
| 海客谈瀛洲 | 李白《梦游天姥吟留别》 | 海上是否有仙山，能否亲眼看一回东海 |
| 树下清风 | 《庄子·逍遥游》 | 不合别人心意，是否仍能过好自己的日子 |

每位人物续谈间隔三个月，已谈话题轮换，不在每次打开时重复给奖励。陪皇嗣读书会增加才学与亲近，允许清静还会略减争竞之心；陪妃嫔谈心会改善心情与情分。对话写入个人纪事与 NPC 记忆。

## 东海之约

皇子公主读到瀛洲时，可以答应日后同行。未兑现的约定保留在钦安殿，不要求当场花费。出游消耗国库 50 万两、精力 2 点，全宫每年一次。

实际到达后，可一起观潮、听舟人讲仙山传闻，或沿岸探访人家。游历增加才学与亲近，访民另增品德。仙人传闻不等于已经证实有仙人；人物会记得亲眼看海以及皇帝是否陪伴，日后的谈话也会提起。途中存档、读档可续接，不能重复领取结果。

## 国师的日常

国师每三个月可讲道一次，讲读逍遥、济世、观星与祈愿，消耗一点精力，增加一点文才。每年可主持一次祈愿，消耗国库 20 万两及一点精力，同时安排施济、增加一点民心。礼佛、寺居与护国寺原有玩法继续独立存在。

## 孕妃问男问女

已报喜（孕二月起）、尚未临盆且在宫中的成年妃嫔，可从钦安殿或人物详情进入。孕二至七月、身体允许者可由宫人陪同到殿廊；孕八月以后、体弱或病中留在本宫，由国师送来祈愿笺。部分孕妃会在地图上主动前往，月推进也可能遇见这段问答；随机场景全宫至少间隔六个月。信佛人物不会被自动安排来访，主动祈愿不会改变宗教兴趣。

| 签笺 | 国师解说 |
| --- | --- |
| 熊罴入梦 | 借《斯干》熊罴为男子之祥的旧说，猜是皇子 |
| 虺蛇游庭 | 借《斯干》虺蛇为女子之祥的旧说，猜是公主，不把蛇说作凶兆 |
| 双星照水 | 原创祥瑞意象，可能被解作龙凤呈祥，也可能是母子相照，不确定胎数 |
| 云开见月 | 原创签意，暂不定男女，先说眼前的照料与等待 |

她会按性格、已有子女和已经知道的丧子经历发问。玩家可陪着解签、说明男孩女孩都盼着见，或留平安灯。每胎只结算一次：精力一点，心情加六、情分加四；留灯另用国库五万两。已保存的原问、签语与回应可以免费重读，下次怀孕重新留笺，旧事保留在个人纪事和记忆中。

签语是人物间的幻想与寄愿，不是医学判断，也不窥探隐瞒小产或孩子生父。它不改变性别、胎数、难产或换婴结果。顺利分娩且母子存活时，赐名后的对白会再提旧笺：猜中、猜错、多胎都有回应；身故、死婴或换婴不套用喜悦的回响。
