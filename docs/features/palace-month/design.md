# 宫城路线、月末与传承

**Status:** implemented · **更新** 2026-11-13 · [GDD](../../GDD.md)

用地图的地点和人物邀约串起一个月。

## 首月路线与节奏

| 顺序 | 地点与动作 | 门槛和返回 |
|---|---|---|
| 教学 | 登基 → 宫城 → 宸极殿看奏折 | 可暂缓选秀。读奏折后可回宫城再考虑。 |
| 练习 | 宫城 ⇄ 后宫、上书房或御花园 | 点宫名直达，点建筑沿宫道走。上书房先看孩子和日常，特定相处才花精力。 |
| 本月收束 | 结束本月 → 处理提醒或换月 → 看后续 | 首月或有将到期邀约时出现复核。可留在本月，也可略过邀约。 |
| 长线 | 教养、立储 → 驾崩或禅位 → 继位 | 有继承资格时续朝，先确认人选与前因。民心归零可进入民变结局。 |

地图用 200 × 128 内部像素和固定宫道。点名直达的入口不靠步行完成，建筑步行每次地图更新最多走 3.5 内部像素。[宫道与换月](../../../js/map.js) · [失国与继位](../../../js/game.js)

## 反馈与试玩

首月确认给出剩余精力和下月信息，赴约提示带人名与目的地。结果与起居注记录已经发生的事。[月末与地图](../../../js/map.js) · [起居注界面](../../../js/views.js)

[ASSUMPTION] 首轮只引导「一份政务＋见一个人＋换月」。将高负荷政务后的一次自选走访作为停顿。观察玩家能否从到期提醒原路赴约、再回到换月入口。已有回归验证取消首月确认不会花精力或推进时间。长期继承目标与首次位置理解需要实玩。[首月回归](../../../tests/palace-improvements.test.cjs)
