# TapTap 认证开发者（个人主体）填写单

> 2026-11-25 已认证通过，实际使用的厂商名称是「允佩工作室」。下文的候选名是认证前的草稿，留作参考。

依据：TapTap《开发者入驻流程和入驻审核规范说明》v4（2026-11-21 查阅）。
本文件只写填写方法，不写任何个人信息。身份证、姓名、地址、手机号只在 TapTap 后台填写。

## 入口

1. 打开 https://developer.taptap.cn/ ，用你的 TapTap 账号登录，系统会自动生成一个未认证的开发者账号。
2. 进入后台后选「认证开发者」→「个人主体」。
   - 不要停在「注册开发者」：注册开发者只能体验部分后台功能，只能建创意工坊游戏，不能提审。
   - 如果已经生成了注册开发者账号，到「财务与管理 → 厂商设置 → 成为认证开发者」申请转换，不用重新建。

## 逐项填写

| 栏目 | 填什么 | 注意 |
| --- | --- | --- |
| 厂商名称 | 朱檐工作室（备选：拾砚工作室、青笺工作室） | 用中文，后缀写「工作室」。不用游戏名、昵称，不带「科技/网络/有限公司」。创建后不能自己改名，改名要提工单 |
| 厂商英文名称（选填） | Zhuyan Studio（对应备选：Shiyan Studio、Qingjian Studio） | 只写英文 |
| 联系邮箱 | 你常用、能收信的邮箱 | 审核进展会发邮件通知 |
| 联系手机号 | 你的手机号 | 要收验证码，本人操作 |
| QQ / 微信（选填，建议填） | 你的 QQ 或微信 | TapTap 工作人员主要用它联系你 |
| 开发者姓名 | 身份证上的姓名 | 不能用昵称或厂商名 |
| 联系地区 & 联系地址 | 省市区 + 详细地址，写到门牌号 | 地区必须和地址对应 |
| 身份证号码 | 身份证上的号码 | 本人填写 |
| 身份证扫描件 | 正反面清晰照片 | 在有效期内、四角完整、无遮挡。加水印时不能挡住姓名、号码、住址、有效期 |

最后勾选《TapTap 平台开发者协议》并提交。工作人员一般 2 个工作日内处理，结果在个人中心的通知里。

## 审核通过后（厂商资料，可稍后补）

位置：开发者中心 → 财务与管理 → 厂商设置 → 厂商资料。

- **厂商简介（草稿）：** 朱檐工作室是一个人的独立游戏工作室，专注古风文字与模拟经营，作品有《宸宫纪》。想做能慢慢玩、每个选择都会留下痕迹的游戏。
