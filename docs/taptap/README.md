- **游戏名：** 宸宫纪

**长简介：**

《宸宫纪》是一款古风皇帝养成文字游戏。你登基为帝，从弘晏元年三月开始执政：批阅六部奏折，处理黄河水患、科场舞弊、边关军饷；主持选秀，迎娶皇后与妃嫔；经营后宫，抚养皇子皇女；组建锦衣卫，查办宫闱旧案。

## 上传（TapTap 官方 CLI）

TapTap 已把 H5 上传迁到官方命令行工具 `@taptap/cli`：

```bash
npm i -g @taptap/cli
taptap-cli auth login
taptap-cli upload-h5-package dist/taptap/chengongji-h5-V1.0.0.zip --dev-id <开发者ID> --app-id <游戏ID> --screen-orientation 1 --dry-run
```

确认无误后把 `--dry-run` 换成 `--yes`。`--screen-orientation 1` 表示竖屏，0 是横屏。上传后先用 `taptap-cli test-qr-code` 生成自测二维码，在手机 TapTap 里实测，再到资料页「游戏下载和获取 → H5 小游戏」选中这个包体。在开发者后台网页上传也可以。

## 还没做 / 要在真机上确认

- **压缩包结构：** TapTap 官方上传工具打出的包是「一个英文文件夹 + index.html」。Issue 里写的是 index.html 直接放在根目录。默认按官方工具的结构打包；如果后台要求根目录，用 `python3 scripts/build-taptap.py --flat` 重新打一个。
- **体积：** 当前约 39MB，在 60MB 以内。TapTap 审核规范里还有一条较旧的「小游戏包体 20MB 以下」，官方文档没写清楚是否适用于 H5。如果被卡，可以用 `--quality 60` 再压，但立绘会明显变糊，压之前先看效果。
- **存档：** TapTap 文档没写 H5 容器里 IndexedDB 能不能用。游戏启动时会依次试 IndexedDB → `tap.setStorageSync` → localStorage，每一种都要先写入、读回成功才会用。真机上请开一局、换一个月，然后彻底关掉 TapTap 再打开，看自动存档还在不在。
- **登录 / 实名 / 防沉迷：** 游戏在 TapTap 内会调用 `tap.login`，但不等结果、也不拦游戏。TapTap 文档没写 H5 的实名和防沉迷由谁来拦。如果审核要求游戏自己处理，需要再改。
- **H5 备案：** CLI 里有 H5 备案流程。试玩版上线前是否必须备案，以开发者后台的提示为准。
- **字体：** 截图配文是用 macOS 自带的宋体排的版，和截图里游戏自身的文字一样，都是系统字体渲染。如果要严格规避字体授权问题，可以把配文换成思源宋体（OFL 开源授权）重新生成。图标上的「宸宫纪」来自游戏封面上的书法，不用字体。
