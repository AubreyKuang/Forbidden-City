## 身份与存档

- 初代太后没有指定立绘时，以开局皇帝的已有seed稳定选择一张；同一局不会随请安、年月、改名或读档换脸。选择不消耗游戏随机数，也不写入或改动存档。
- 传代优先保留太后保存的portrait快照：先帝皇后升为太后沿用皇后原图；另外尊为太后的生母也保留自己的原图，包括剧情妃专属编号。
- 旧档若有personId但缺少portrait，先从保留的先朝家族、先朝妃嫔档案或现存人物中找回。同一身份完全无法找回时保留旧版9号后备形象，绝不从新图库抽一个人替代。
- 已有portrait快照或明确指定的portraitOverride/artPortrait不被新图库覆盖。其他人的母亲仍使用原有逻辑；18张新图不混入随机妃嫔、父兄或官员图库。
- 0–440号的图集、人物编号及存档映射不变；钩弋夫人仍是422号。

## 素材来源与复现

完整编号、原图SHA-256、裁切坐标与图集位置见[dowager-portrait-sources.json](dowager-portrait-sources.json)。原图按用户确认顺序逐人裁切、等比缩放，无重绘、变形或首饰位置修改。

```sh
python3 scripts/build-dowager-portraits.py /path/to/generated_images
```

输出三张1792×1120 WebP，每张前六格有效、末两格透明。立绘接入及传代规则由`tests/palace-dowager-portraits.test.cjs`验证。
