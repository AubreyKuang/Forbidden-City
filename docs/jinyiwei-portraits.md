# 锦衣卫与选定官员立绘的固定编号

编号是程序使用的零基 `portraitCell` / `portraitOverride` 值，**不要加一**。
钩弋夫人仍为 **422**；所有更早编号均保持不变。

## 锦衣卫：新版六张，423–428

采用修正后全部戴官帽、飞鱼纹袍服与佩刀的版本，严格按原预览图
从左到右、先上排后下排编号。这六张不进入普通官员／父兄随机池。

| 原预览位置 | 形象 | 固定编号 |
| --- | --- | ---: |
| 上排左（1） | 玄黑金绣 | 423 |
| 上排中（2） | 朱红金绣 | 424 |
| 上排右（3） | 藏青银绣 | 425 |
| 下排左（4） | 墨绿金绣 | 426 |
| 下排中（5） | 月白金绣 | 427 |
| 下排右（6） | 绛紫金绣 | 428 |

稳定常量：`JINYIWEI_PORTRAITS === [423,424,425,426,427,428]`，
配色名称见 `JINYIWEI_PORTRAIT_LABELS`。

```js
officer.jinyiwei = true;
officer.artPortrait = JINYIWEI_PORTRAITS[0]; // 玄黑金绣，423
officer.portraitOverride = JINYIWEI_PORTRAITS[0]; // 如需强制固定该张
```

也可调用 `assignJinyiweiPortrait(officer)`，按人物自身的种子确定一张，
一旦在专用池中就保留。新锦衣卫指挥使自动使用这六张。
旧存档中的锦衣卫会按其原人物种子固定显示新制服；只映射显示，不修改
旧事务日志中的世界数据，因此未完的事件仍能续接。人工设置的
`portraitOverride` 优先；普通官员与父兄已有面孔继续保留。

## 图集与来源

- 新版锦衣卫图集：`assets/images/palace-jinyiwei.webp`，起始 423，四列两行。
- 旧版选定四张：`assets/images/palace-officials-selected.webp`，起始 429，四列一行。

  原图，只做裁切、等比缩放与透明图集排版。
