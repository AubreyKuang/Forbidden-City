# 宫中故事：典故生新枝

新增 27 组可主动走近的故事，共 54 条回应及各自后话。与已有个人经历并行，入口在人物详情、宫城动向及上书房、文渊阁、御花园。接受一次消耗 1 点精力；涉及花费的选项另写明国库支出。两个月后可再听后话，并留下人物纪事与主观记忆；此后一年内，普通闲谈可能提起这件事。

这些故事是架空宫廷中的改编。史书、史书注文、志人笔记、礼学、技术笔记、宫廷制度与原创故事分别标注；人物台词及玩家分支均为创作，不冒充古人原话。跨朝代素材也不表示所有礼制属于同一时代。

## 人物如何进入故事

皇嗣有好奇、好胜、仁厚、内敛、爽直、灵动、审慎、自矜八种稳定性情。教养仍改变才学、武艺等本领，性情不随最高属性来回跳变。幼童、学龄儿童、少年分别使用不同对白；婴幼儿、病中、拘禁、离宫、思念冷宫母亲等处境优先于普通心声。旧存档按人物原有种子补齐性情，读取面板不会消耗随机数。

故事不仅检查性情，还结合年龄、身份、才学、武艺、季节、国库、实际礼物记忆，以及与另一人的真实关系。亲蚕由皇后参与，只带准许往来的亲生或抚养孩子；公主问军粮限定 12–17 岁，并以课堂推演承接志向。病中朋友通过传话收到问候，不被要求到上书房出场。

## 节奏与连续性

- 全宫至少相隔三个月才产生一条新故事，最多三条当前可见故事；同一主角收尾后至少间隔一年，同一题材在全宫间隔三年。一个人物不会同时被两条新故事借用。
- 未接受的邀请保留至多五个月，并继续校验当时的年龄、季节和对象；可暂缓，也可明确让它过去，不扣属性、不制造处罚。
- 接受后保存原人物编号、分支与到期月份。跨过生日、季节或改善关系后，原来的后话仍可继续。临时病弱、清修等期间暂停出场；人物死亡、离宫移出或改朝换代会终止未完事项，不拿另一人代替。
- 后话不额外收取精力，不重复奖励。双方分别留下记忆；孩子或对手不会自动把主角的心声当成自己的想法。
- 原有低龄课业相应缩小为短文、纸笔小账和上学路线；顽童事件限定合适年龄与性情，婴儿不再抽到贪吃冰酪的叙述。
